---
title: "Seedance 素材"
description: "管理 Seedance 素材组和素材：把公网图片、视频、音频登记为素材，处理完成后在视频生成中通过 asset:// 引用。"
---

- 支持三种调用风格：`/v1/seedance/asset/*`、火山标准 REST `/api/v3/asset/*`、火山 SDK Action `POST /?Action=...`。三种风格功能相同，只是字段命名和响应包裹不同，见 [调用风格](#调用风格)。
- 素材按账户隔离：同一账户下的所有 API Key 共享素材组和素材，其他账户无法查询、修改或删除。
- 只接收公网 URL，不支持本地文件上传，也不支持 `data:` 格式的 Base64 数据。
- 创建素材是异步的：接口立即返回素材 `Id`，素材可能仍在处理。请每 2 秒 [查询素材](#查询素材) 一次，直到 `Status` 为 `Active`。
- 素材可用后，在 [Seedance 视频生成](/api-reference/videos/seedance/seedance-2-0) 的 `content` 中把 URL 写成 `asset://<Id>` 即可引用，见 [在视频生成中使用](#在视频生成中使用)。

```python Python
import time
import requests

API_KEY = "sk-你的密钥"
BASE = "https://api.nodylink.com"
headers = {"Authorization": f"Bearer {API_KEY}"}


def call(path: str, body: dict) -> dict:
    resp = requests.post(f"{BASE}/v1/seedance/asset{path}", headers=headers, json=body)
    data = resp.json()
    if not resp.ok:
        raise RuntimeError(data["error"]["message"])
    return data["result"]


# 不传 group_id 时登记到平台默认组；需要按组管理时先创建素材组再传 group_id
asset_id = call("/create", {
    "url": "https://example.com/character.png",
    "asset_type": "Image",
    "name": "character.png",
})["Id"]

while True:
    status = call("/get", {"id": asset_id})["Status"]
    if status == "Active":
        break
    if status == "Failed":
        raise RuntimeError("素材处理失败，请检查 URL、格式、尺寸或时长")
    time.sleep(2)

print(f"asset://{asset_id}")
```

```javascript Node.js
const API_KEY = "sk-你的密钥";
const BASE = "https://api.nodylink.com";

const call = async (path, body) => {
  const resp = await fetch(`${BASE}/v1/seedance/asset${path}`, {
    method: "POST",
    headers: {
      Authorization: `Bearer ${API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(body),
  });
  const data = await resp.json();
  if (!resp.ok) throw new Error(data.error?.message ?? `HTTP ${resp.status}`);
  return data.result;
};

// 不传 group_id 时登记到平台默认组；需要按组管理时先创建素材组再传 group_id
const { Id: assetId } = await call("/create", {
  url: "https://example.com/character.png",
  asset_type: "Image",
  name: "character.png",
});

while (true) {
  const { Status } = await call("/get", { id: assetId });
  if (Status === "Active") break;
  if (Status === "Failed") throw new Error("素材处理失败，请检查 URL、格式、尺寸或时长");
  await new Promise((r) => setTimeout(r, 2000));
}

console.log(`asset://${assetId}`);
```

## 调用风格

| 风格 | 地址 | 鉴权 | 字段命名 | 成功响应 |
| - | - | - | - | - |
| v1 | `POST /v1/seedance/asset/<操作路径>` | `Authorization: Bearer <API Key>` | snake_case，例如 `group_id` | `{"success": true, "result": {...}}` |
| 火山标准 REST | `POST /api/v3/asset/<操作路径>` | `Authorization: Bearer <API Key>` | snake_case，例如 `group_id` | `{"result": {...}}` |
| 火山 SDK Action | `POST /?Action=<Action>&Version=2024-01-01` | `x-api-key: <API Key>` 或 `Authorization: Bearer <API Key>` | PascalCase，例如 `GroupId` | `{"ResponseMetadata": {...}, "Result": {...}}` |

三种风格的区别：

- **默认组。** 只有 v1 风格创建素材时可以不传组 ID，素材会登记到平台默认组。火山标准 REST 和 Action 风格必须传组 ID。
- **列出素材组。** v1 风格的响应结构与其他接口不同，见 [列出素材组](#列出素材组)。
- **Action 版本号。** `Version` 固定为 `2024-01-01`。
- **Action 鉴权。** 火山 SDK 会自动附带 HMAC 签名，本接口忽略签名，只认 `x-api-key` 或 `Authorization: Bearer`。只带签名会返回 401 `MissingAPIKey`。

<CodeGroup>
```bash v1
curl https://api.nodylink.com/v1/seedance/asset/get \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"id": "asset-20261031114703-96kw4"}'
```

```bash 火山标准 REST
curl https://api.nodylink.com/api/v3/asset/get \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"id": "asset-20261031114703-96kw4"}'
```

```bash 火山 SDK Action
curl "https://api.nodylink.com/?Action=GetAsset&Version=2024-01-01" \
  -H "x-api-key: sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"Id": "asset-20261031114703-96kw4"}'
```
</CodeGroup>

    "Version": "2024-01-01"

## 接口一览

所有操作都是 `POST`，请求体为 JSON。v1 和火山标准 REST 的操作路径相同，只是前缀不同。

| 操作 | v1 / 火山标准 REST 路径 | Action |
| - | - | - |
| [创建素材组](#创建素材组) | `/groups` | `CreateAssetGroup` |
| [列出素材组](#列出素材组) | `/groups/list` | `ListAssetGroups` |
| [查询素材组](#查询素材组) | `/groups/get` | `GetAssetGroup` |
| [更新素材组](#更新素材组) | `/groups/update` | `UpdateAssetGroup` |
| [删除素材组](#删除素材组) | `/groups/delete` | `DeleteAssetGroup` |
| [创建素材](#创建素材) | `/create` | `CreateAsset` |
| [查询素材](#查询素材) | `/get` | `GetAsset` |
| [列出素材](#列出素材) | `/list` | `ListAssets` |
| [更新素材](#更新素材) | `/update` | `UpdateAsset` |
| [删除素材](#删除素材) | `/delete` | `DeleteAsset` |

v1 风格另外保留 `GET /v1/seedance/asset/{id}` 查询素材，效果与 `POST /v1/seedance/asset/get` 相同。

下文的请求参数按「v1 / REST 字段」和「Action 字段」两列列出，响应示例以 v1 风格为准。

## 素材组

素材组用于归类素材。素材组和组内素材只对创建它的账户可见。

### 创建素材组

`POST /v1/seedance/asset/groups` · `POST /api/v3/asset/groups` · `Action=CreateAssetGroup`

| v1 / REST 字段 | Action 字段 | 类型 | 说明 |
| - | - | - | - |
| `name` | `Name` | string | 必填，素材组名称，不超过 64 个字符 |
| `description` | `Description` | string | 选填，素材组描述，不超过 1024 个字符 |

```json 200
{
  "success": true,
  "result": {
    "Id": "group-20261031114658-tsb52"
  }
}
```

请保存 `result.Id`，后续操作通过它指定素材组。

### 列出素材组

`POST /v1/seedance/asset/groups/list` · `POST /api/v3/asset/groups/list` · `Action=ListAssetGroups`

列出当前账户创建的素材组，最新创建的排在前面。请求体可以为空。

| v1 / REST 字段 | Action 字段 | 类型 | 说明 |
| - | - | - | - |
| `page_number` | `PageNumber` | integer | 选填，页码，从 1 开始，默认 `1` |
| `page_size` | `PageSize` | integer | 选填，每页条数，取值 1～100，默认 `10` |

v1 风格的响应把列表放在顶层：

```json v1
{
  "success": true,
  "groups": [
    {
      "Id": "group-20261031114658-tsb52",
      "Name": "角色素材",
      "Description": "主角参考图",
      "CreateTime": "2026-10-31T03:46:58Z"
    }
  ],
  "total": 1,
  "page_number": 1,
  "page_size": 10
}
```

火山标准 REST 和 Action 风格放在 `result` / `Result` 中：

```json 火山标准 REST
{
  "result": {
    "Items": [
      {
        "Id": "group-20261031114658-tsb52",
        "Name": "角色素材",
        "Description": "主角参考图",
        "CreateTime": "2026-10-31T03:46:58Z"
      }
    ],
    "PageNumber": 1,
    "PageSize": 10,
    "TotalCount": 1
  }
}
```

</Warning>

## 素材

### 创建素材

`POST /v1/seedance/asset/create` · `POST /api/v3/asset/create` · `Action=CreateAsset`

把公网素材登记到指定素材组，立即返回素材 `Id`，不等待处理完成。

| v1 / REST 字段 | Action 字段 | 类型 | 说明 |
| - | - | - | - |
| `url` | `Url` | string | 必填，素材的公网直链，必须以 `http://` 或 `https://` 开头，无需登录即可直接下载，建议使用 HTTPS |
| `asset_type` | `AssetType` | string | 选填，素材类型：`Image`、`Video` 或 `Audio`，不区分大小写，默认 `Image` |
| `name` | `Name` | string | 选填，素材名称，不超过 64 个字符。不传时使用 URL 中的文件名 |
| `group_id` | `GroupId` | string | 素材组 ID，必须是当前账户创建的素材组。v1 风格选填，不传时登记到平台默认组；火山标准 REST 和 Action 风格必填 |

```json 200
{
  "success": true,
  "result": {
    "Id": "asset-20261031114703-96kw4"
  }
}
```

<Note>
  平台默认组由所有账户共用，所以只能通过素材 ID 查询、更新、删除其中属于你的素材，不能列出、查询或删除默认组本身，也不能在创建时显式传入默认组 ID。需要按组列出素材时，请先 [创建素材组](#创建素材组)。
</Note>

### 支持格式与限制

| 素材类型 | 格式 | 限制 |
| - | - | - |
| `Image` | jpeg、png、webp、bmp、tiff、gif、heic / heif | 宽高比 0.4～2.5，宽高 300～6000 px，单张小于 30 MB |
| `Video` | mp4、mov | 时长 1.8～15.2 秒，高度 300～6000 px |
| `Audio` | mp3、wav | 需提供可直接下载的音频文件 URL |

### 查询素材

`POST /v1/seedance/asset/get` · `POST /api/v3/asset/get` · `Action=GetAsset` · `GET /v1/seedance/asset/{id}`

创建后素材可能仍在处理。建议每 2 秒查询一次，直到 `Status` 为 `Active`。

| v1 / REST 字段 | Action 字段 | 类型 | 说明 |
| - | - | - | - |
| `id` | `Id` | string | 必填，素材 ID |

```json 200
{
  "success": true,
  "result": {
    "Id": "asset-20261031114703-96kw4",
    "Name": "character.png",
    "AssetType": "Image",
    "GroupId": "group-20261031114658-tsb52",
    "Status": "Active",
    "URL": "https://ark-media-asset.tos-cn-beijing.volces.com/...png?X-Tos-Signature=...",
    "Moderation": {
      "Strategy": "Default"
    },
    "ProjectName": "default",
    "CreateTime": "2026-10-31T03:47:03Z",
    "UpdateTime": "2026-10-31T03:47:04Z"
  }
}
```

| 字段 | 类型 | 说明 |
| - | - | - |
| `Id` | string | 素材 ID |
| `Name` | string | 素材名称 |
| `AssetType` | string | 素材类型：`Image`、`Video` 或 `Audio` |
| `GroupId` | string | 所属素材组 ID |
| `Status` | string | 处理状态，见 [处理状态](#处理状态) |
| `URL` | string | 处理后的素材访问地址，是有有效期的签名 URL，不能作为素材的永久标识 |
| `CreateTime` | string | 创建时间，UTC ISO 8601 格式 |
| `UpdateTime` | string | 最近更新时间，UTC ISO 8601 格式 |

### 处理状态

| 状态 | 含义 | 处理建议 |
| - | - | - |
| `Pending` / `Processing` | 处理中 | 继续轮询 |
| `Active` | 处理完成，素材可用 | 停止轮询，在视频生成中引用 |
| `Failed` | 处理失败 | 停止轮询，检查素材 URL 能否直接下载，以及格式、尺寸、时长是否符合 [限制](#支持格式与限制) |

| v1 / REST 字段 | Action 字段 | 类型 | 说明 |

## 在视频生成中使用

素材变为 `Active` 后，在 Seedance 视频生成请求的 `content` 中，把对应的 URL 写成 `asset://<Id>`：

```json
{
  "model": "Doubao-Seedance-2.0",
  "content": [
    {"type": "text", "text": "图片1中的角色在海边奔跑，镜头跟随"},
    {"type": "image_url", "image_url": {"url": "asset://asset-20261031114703-96kw4"}, "role": "reference_image"}
  ],
  "ratio": "16:9",
  "duration": 5
}
```

视频和音频素材同理，分别写在 `video_url.url` 和 `audio_url.url` 中。

<Warning>
  - 素材 ID 只能在本平台的 Seedance 视频生成中使用。
  - `URL` 会过期，请保存素材 `Id`，不要保存 `URL`。
</Warning>

## 错误响应

v1 和火山标准 REST 风格使用 OpenAI 风格的错误体，格式见 [错误码](/errors)。`message` 末尾的 `(request id: ...)` 是本次请求的唯一 ID。

Action 风格把错误放在 `ResponseMetadata.Error` 中，请求 ID 见 `ResponseMetadata.RequestId`：

```json
{
  "ResponseMetadata": {
    "RequestId": "202610310347158300861225tjPSa7Z",
    "Action": "GetAsset",
    "Version": "2024-01-01",
    "Error": {
      "Code": "seedance_asset_forbidden",
      "Message": "素材或素材组不存在，或当前账号无权访问"
    }
  }
}
```

<Note>
  API Key 无效等鉴权错误由网关统一返回，三种风格都使用 OpenAI 风格的错误体。
</Note>

### 错误码

| 错误码 | 状态码 | 说明 |
| - | - | - |
| `invalid_request` | 400 | 请求体不是合法的 JSON |
| `invalid_url` | 400 | `url` 缺失、不是 http(s) 链接，或使用了 `data:` 格式 |
| `invalid_asset_type` | 400 | `asset_type` 不是 `Image`、`Video`、`Audio` 之一 |
| `invalid_asset_name` | 400 | 素材名称超过 64 个字符 |
| `missing_asset_id` | 400 | 未传素材 ID |
| `missing_asset_name` | 400 | 更新素材时未传 `name`，或为空 |
| `missing_group_id` | 400 | 未传素材组 ID；火山标准 REST 和 Action 风格创建素材时必须传 |
| `missing_group_name` | 400 | 创建素材组时未传 `name`，或更新时 `name` 为空字符串 |
| `invalid_group_name` | 400 | 素材组名称超过 64 个字符 |
| `invalid_group_description` | 400 | 素材组描述超过 1024 个字符 |
| `missing_update_fields` | 400 | 更新素材组时 `name` 和 `description` 都没传 |
| `invalid_page_number` | 400 | `page_number` 小于 1 |
| `invalid_page_size` | 400 | `page_size` 不在 1～100 之间 |
| `invalid_group_ids` | 400 | Action 风格 `ListAssets` 的 `Filter.GroupIds` 传了多个组 |
| `InvalidAction` | 400 | Action 风格的 `Action` 不受支持 |
| `InvalidVersion` | 400 | Action 风格的 `Version` 不是 `2024-01-01` |

| `seedance_asset_forbidden` | 403 | 素材或素材组不存在、已删除、属于其他账户，或操作的是平台默认组 |

| `seedance_upstream_rejected` | 422 | 素材服务拒绝了请求，原因见 `message` |
| `seedance_upstream_rate_limited` | 429 | 素材服务限流，请退避后重试 |
