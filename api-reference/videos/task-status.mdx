---
title: "查询视频任务"
api: "GET /v2/videos/generations/{task_id}"
description: "查询 Seedance、Wan、MiniMax、Nodydance 视频生成任务的状态和结果。"
---

视频生成接口提交后返回任务 `id`，用本接口轮询任务状态。任务成功后，视频链接在 `data` 中。

- 视频生成通常需要 1～10 分钟，建议每 10 秒左右查询一次。
- 只能查询当前账户提交的任务。
- 视频链接可能会过期，拿到后请及时下载转存。

## 鉴权

<ParamField header="Authorization" type="string" required>
  `Bearer <API Key>`。需要与提交任务时属于同一账户。
</ParamField>

## 路径参数

<ParamField path="task_id" type="string" required>
  视频生成接口返回的 `id`。
</ParamField>

## 响应

<ResponseField name="task_id" type="string">
  任务 ID。
</ResponseField>

<ResponseField name="action" type="string">
  任务类型：`textGenerate` 表示纯文生视频，`generate` 表示包含图片、视频或音频参考。
</ResponseField>

<ResponseField name="status" type="string">
  任务状态：

  | 状态 | 含义 |
  | - | - |
  | `NOT_START` | 任务已创建，尚未提交到上游 |
  | `SUBMITTED` | 已提交到上游 |
  | `QUEUED` | 上游排队中 |
  | `IN_PROGRESS` | 生成中 |
  | `SUCCESS` | 成功，`data` 中包含视频链接 |
  | `FAILURE` | 失败，原因见 `fail_reason`，费用已自动退回 |
</ResponseField>

<ResponseField name="fail_reason" type="string">
  失败原因。非失败状态下为空字符串。
</ResponseField>

<ResponseField name="submit_time" type="integer">
  提交时间，Unix 时间戳（秒）。
</ResponseField>

<ResponseField name="start_time" type="integer">
  开始生成时间，Unix 时间戳（秒）。未开始时为 `0`。
</ResponseField>

<ResponseField name="finish_time" type="integer">
  完成时间，Unix 时间戳（秒）。未完成时为 `0`。
</ResponseField>

<ResponseField name="progress" type="string">
  任务进度，例如 `50%`。
</ResponseField>

<ResponseField name="data" type="object | null">
  上游返回的任务结果，任务完成前可能为 `null`。视频链接的位置因模型和线路而异：

  | 位置 | 适用 | 说明 |
  | - | - | - |
  | `data.task.id` | Seedance | 上游任务号，`cgt-` 开头。[Seedance 2.5 Full](/api-reference/videos/seedance/seedance-2-5-full) 样片转正式片时，`draft_task.id` 填这个值，不要填外层 `task_id` |
  | `data.task.outputs[0]` | Seedance | Seedance格式，火山引擎原生链接 |
  | `data.task.usage` | Seedance | token 用量 |
  | `data.task.last_frame_url` | Seedance | 尾帧图片，请求时设置了 `return_last_frame` 才有 |
  | `data.task.resolution` | Seedance | 实际分辨率，例如 `720p`，部分线路在成功后返回 |
  | `data.task.duration` | Seedance | 实际时长（秒），部分线路在成功后返回 |
  | `data.task.ratio` | Seedance | 实际宽高比，例如 `16:9`，部分线路在成功后返回 |
  | `data.task.draft` | Seedance | 是否为样片。样片任务为 `true`，普通任务和正式片为 `false`。部分线路在成功后返回 |
  | `data.result.videos[0].url[0]` | Wan、MiniMax H3 Comfy | 视频链接，多数其他模型使用这种格式 |
  | `data.result_url` | Nodydance 2.5 | 视频链接 |

  建议按下方示例依次尝试，取第一个非空值。
</ResponseField>

## 提取视频链接

<CodeGroup>
```python Python
def extract_result(data: dict) -> tuple[str | None, str | None]:
    """返回 (视频链接, 尾帧链接)"""
    if not data:
        return None, None
    task = data.get("task") or {}
    content = data.get("content") or {}
    videos = (data.get("result") or {}).get("videos") or [{}]
    video = (
        (task.get("outputs") or [None])[0]
        or content.get("video_url")
        or (videos[0].get("url") or [None])[0]
        or data.get("result_url")
    )
    last_frame = task.get("last_frame_url") or content.get("last_frame_url")
    return video, last_frame
```

```javascript Node.js
function extractResult(data) {
  const video =
    data?.task?.outputs?.[0] ??
    data?.content?.video_url ??
    data?.result?.videos?.[0]?.url?.[0] ??
    data?.result_url ??
    null;
  const lastFrame = data?.task?.last_frame_url ?? data?.content?.last_frame_url ?? null;
  return { video, lastFrame };
}
```
</CodeGroup>

## 错误响应

| 状态码 | 说明 |
| - | - |
| `400` | 任务不存在，或不属于当前账户，响应为 `{"code": "task_not_exist", "message": "task_not_exist", "data": null}` |
| `401` | API Key 无效 |
