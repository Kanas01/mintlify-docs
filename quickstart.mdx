## 准备工作

- 一个 NODYLINK 账户。没有账户时，在 [登录页](https://nodylink.com/login) 用邮箱注册。
- 账户里有可用余额。可以在 [充值中心](https://nodylink.com/dashboard/billing) 在线充值或使用兑换码。

## 发出第一条请求

<Steps>
  <Step title="创建 API Key">
    打开 [控制台 → API 密钥](https://nodylink.com/dashboard/keys)，点击新建。密钥以 `sk-` 开头，只在创建时完整显示一次，请妥善保存。

    <Warning>
      不要把 API Key 写进前端代码或提交到代码仓库。建议放在环境变量中：

      ```bash
      export NODYLINK_API_KEY="sk-你的密钥"
      ```
    </Warning>
  </Step>

  <Step title="确认可用模型">
    在 [模型广场](https://nodylink.com/market) 查看模型 ID 和单价，或者调用 [模型列表接口](/api-reference/models/list) 获取当前密钥可用的模型：

    ```bash
    curl https://api.nodylink.com/v1/models \
      -H "Authorization: Bearer $NODYLINK_API_KEY"
    ```
  </Step>

  <Step title="调用对话接口">
    <CodeGroup>
    ```bash cURL
    curl https://api.nodylink.com/v1/chat/completions \
      -H "Authorization: Bearer $NODYLINK_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "gpt-6",
        "messages": [{"role": "user", "content": "你好"}]
      }'
    ```

    ```python Python
    import os
    from openai import OpenAI

    client = OpenAI(
        base_url="https://api.nodylink.com/v1",
        api_key=os.environ["NODYLINK_API_KEY"],
    )

    resp = client.chat.completions.create(
        model="gpt-6",
        messages=[{"role": "user", "content": "你好"}],
    )
    print(resp.choices[0].message.content)
    ```

    ```javascript Node.js
    import OpenAI from "openai";

    const client = new OpenAI({
      baseURL: "https://api.nodylink.com/v1",
      apiKey: process.env.NODYLINK_API_KEY,
    });

    const resp = await client.chat.completions.create({
      model: "gpt-6",
      messages: [{ role: "user", content: "你好" }],
    });
    console.log(resp.choices[0].message.content);
    ```
    </CodeGroup>
  </Step>

  <Step title="查看用量">
    调用完成后，在 [使用日志](https://nodylink.com/dashboard/logs) 中可以看到这次请求的模型、token 数和扣费金额。
  </Step>
</Steps>

## 生成图片和视频

图像和视频生成都是异步任务：提交后立即拿到任务 ID，再轮询查询接口获取结果。

<CodeGroup>
```bash 图片
# 1. 提交任务
curl https://api.nodylink.com/v1/images/generations \
  -H "Authorization: Bearer $NODYLINK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-image-2", "prompt": "一只橘猫坐在窗台上看夕阳", "size": "1:1"}'

# 2. 用返回的 task_id 查询结果
curl https://api.nodylink.com/v1/images/tasks/<task_id> \
  -H "Authorization: Bearer $NODYLINK_API_KEY"
```

```bash 视频
# 1. 提交任务（请求体与火山方舟官方格式一致）
curl https://api.nodylink.com/v2/videos/generations \
  -H "Authorization: Bearer $NODYLINK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "content": [{"type": "text", "text": "小猫对着镜头打哈欠"}],
    "ratio": "16:9",
    "duration": 5
  }'

# 2. 用返回的 id 查询结果
curl https://api.nodylink.com/v2/videos/generations/<task_id> \
  -H "Authorization: Bearer $NODYLINK_API_KEY"
```
</CodeGroup>
